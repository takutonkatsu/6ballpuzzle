# ホーム主要アイコン生成プロンプト

## 共通指定

以下の共通指定をすべてのアイコン生成に入れてください。

```text
スマホゲーム「ヘキサゴン」のホーム画面下部ナビ用アイコン。黒基調の近未来ネオンUIに合う、高級感のある3Dゲームアイコン。背景透過。正方形。中央に大きく分かりやすいシンボル。六角形モチーフを少し入れる。過度な文字や数字は入れない。小さく表示しても識別できる。光沢、リムライト、控えめな発光。チープな絵文字風ではなく、App Store向けゲームのUIアセット品質。
```

推奨出力:

- サイズ: 1024 x 1024
- 背景: 透過PNG
- 保存先: `assets/images/HomeNav/`
