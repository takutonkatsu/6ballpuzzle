# ゲーム内カラー定義

色の実装値は `lib/ui/theme/game_theme_colors.dart` を正とします。

## 基礎色

| 用途 | 色 | 値 |
| --- | --- | --- |
| 背景 | 深い黒紺 | `#080A12` |
| 通常パネル | 暗い青黒 | `#111827` |
| 強調パネル | 深い青 | `#0D1826` |
| 水色テーマ | 明るい水色 | `#40F7FF` |
| 水色系の枠線 | 落ち着いた水色 | `#22D4E3` |
| 自分側 | 青 | `#2979FF` |
| 相手側 | 赤 | `#FF5252` |

## ゲームモード色

| モード | 色 | 値 |
| --- | --- | --- |
| ランク戦 | 紫 | `#8F3DFF` |
| エンドレス | エメラルド | `#00E68A` |
| コンピュータ対戦 | 黄色 | `#FFEA00` |
| フレンド対戦 | ピンク | `#FF4081` |
| アリーナ | 水色テーマ | `#40F7FF` |

## 運用ルール

- 文字には光沢やぼかしの `TextStyle.shadows` を使わず、太さ・色・余白で強調する。
- 水色の文字やアイコンは `cyan`、枠線は `cyanBorder` を使う。
- 対戦画面では、自分に関わる主要色は `blueSide`、相手に関わる主要色は `redSide` を使う。
- モード選択、モード別ダイアログ、履歴、ランキングなどのモード識別にはゲームモード色を使う。
